# 觉心师父回复助手 · Android悬浮球App

> 广西兴安回龙寺 · 释觉心法师 · 微信回复利器

## 这是什么

一个Android悬浮窗助手，在微信等任何App上层运行：

```
微信聊天中 → 复制弟子消息 → 悬浮球自动弹出 → 3条师父回复 → 一键复制回微信
```

**不切换App、不需要网络、纯本地引擎，7大场景智能匹配。**

---

## 快速开始

### 方式一：GitHub Actions自动构建（推荐，无需装任何工具）

1. 将本项目推送到你自己的GitHub仓库
2. GitHub Actions自动构建APK（约5分钟）
3. 在Actions页面下载APK安装

### 方式二：Android Studio本地构建

1. 安装 [Android Studio](https://developer.android.com/studio)
2. 打开此目录，Gradle自动同步
3. 连接手机 → 点击 Run

---

## 安装后三步上手

| 步骤 | 操作 |
|------|------|
| **1. 授权** | 打开App → 授予「悬浮窗」权限 |
| **2. 启动** | 点「启动助手」→ 屏幕边缘出现🙏悬浮球 |
| **3. 使用** | 微信中复制弟子消息 → 悬浮球自动弹出回复面板 → 点一条复制 → 回微信粘贴 |
